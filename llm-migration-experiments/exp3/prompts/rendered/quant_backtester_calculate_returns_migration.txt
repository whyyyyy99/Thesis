### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame → polars.DataFrame  [doc not in corpus — see guidance below]
  pandas.DataFrame.columns → polars.DataFrame.columns
    Notes: Returns column labels.
    Limitations: Use df.columns.
    Discrepancies: Mostly direct; Polars columns are the main labels because there is no row index.
  pandas.DataFrame.index → No direct Polars equivalent; use explicit index column or with_row_index()  [no direct Polars equivalent — see guidance below]
  pandas.Series.cumprod → polars.Series.cum_prod
    Notes: Returns cumulative product.
    Limitations: Use cum_prod; review null and dtype behavior.
    Discrepancies: pandas has skipna; Polars cumulative null behavior may differ.
  pandas.Series.fillna → polars.Series.fill_null
    Notes: Fills missing values with a value or method.
    Limitations: Use fill_null for nulls and fill_nan for floating NaN values.
    Discrepancies: pandas fillna covers several missing markers, while Polars separates null from NaN.
  pandas.Series.pct_change → polars.Series.pct_change
    Notes: Computes fractional change from a prior element.
    Limitations: Use pct_change; pandas fill_method/freq need manual review.
    Discrepancies: pandas has time-index/fill semantics, while Polars is positional unless explicitly time-based.
  pandas.Series.replace → polars.Series.replace
    Notes: Replaces values according to scalar/list/dict mappings.
    Limitations: Use replace; review regex and dtype-changing replacements manually.
    Discrepancies: pandas replace supports broad regex/nested patterns, while Polars replacement is more typed and expression-based.
  pandas.Series.shift → polars.Series.shift
    Notes: Shifts values by a number of periods.
    Limitations: Use shift(n) for value shift; pandas freq index shift needs manual datetime-column logic.
    Discrepancies: pandas can shift values or index frequency, while Polars shifts values only unless datetime columns are explicitly modified.

### Source pandas Behavior
Brief descriptions of the source pandas APIs to clarify their intended behavior.

  pandas.DataFrame: Two-dimensional, size-mutable, potentially heterogeneous tabular data.

Data structure also contains labeled axes (rows and columns).
Arithmetic operations align on both row and column labels. Can be
thought of as a dict-like container for Series objects.
  pandas.DataFrame.columns: The column labels of the DataFrame.

This property holds the column names as a pandas Index object.
It provides an immutable sequence of column labels that can be
used for data selection, renaming, and alignment in DataFrame operations.
  pandas.DataFrame.index: The index (row labels) of the DataFrame.

The index of a DataFrame is a series of labels that identify each row.
The labels can be integers, strings, or any other hashable type. The index
is used for label-based access and alignment, and can be accessed or
modified using this attribute.
  pandas.Series.cumprod: Return cumulative product over a Series.

Returns a Series of the same size containing the cumulative
product.

This parameter is unused and defaults to 0.

Exclude NA/null values. If entire Series is NA, the result will be NA.
  pandas.Series.fillna: Fill NA/NaN values with value.

Value to use to fill holes (e.g. 0), alternately a
dict/Series/DataFrame of values specifying which value to use for
each index (for a Series) or column (for a DataFrame).
  pandas.Series.pct_change: Fractional change between the current and a prior element.

Computes the fractional change from the immediately previous row by
default. This is useful in comparing the fraction of change in a time
series of elements.
  pandas.Series.replace: Replace values given in to_replace with value.

Values of the Series/DataFrame are replaced with other values dynamically.
This differs from updating with .loc or .iloc, which require
you to specify a location to update with some value.
  pandas.Series.shift: Shift index by desired number of periods with an optional time freq.

When freq is not passed, shift the index without realigning the data.
If freq is passed (in this case, the index must be date or datetime,
or it will raise a NotImplementedError), the index will be
increased using the periods and the freq.
