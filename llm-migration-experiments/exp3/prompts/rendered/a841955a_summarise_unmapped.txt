## Rules

- Preserve the observable output contract, including required columns, column order when semantically meaningful, and compatible return type.
- Polars has no row index; handle index-dependent logic explicitly using column operations.
- Do not alter behavior on edge cases such as empty input, null values, duplicate keys, or single-column outputs.
- Prefer vectorised Polars expressions over element-wise operations wherever possible.
- Use valid Polars APIs only; do not copy pandas-only idioms into Polars.
- Include all necessary imports at the top.
