## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame.apply → polars.DataFrame.map_rows
    Notes: Applies a function along DataFrame rows or columns.
    Limitations: Avoid direct UDF migration when possible; rewrite as native Polars expressions.
    Discrepancies: pandas apply(axis=...) is flexible, while Polars favors typed expressions and row UDFs are slower.
  pandas.DataFrame.columns → polars.DataFrame.columns
    Notes: Returns column labels.
    Limitations: Use df.columns.
    Discrepancies: Mostly direct; Polars columns are the main labels because there is no row index.
  pandas.DataFrame.loc → polars.DataFrame.filter
    Notes: Access a group of rows and columns by label(s) or a boolean array.
    Limitations: Polars has no label-based index; replace df.loc[mask] with df.filter(mask) and df.loc[:, cols] with df.select(cols).
    Discrepancies: pandas loc relies on the Index; Polars is index-free and uses filter/select/slice for the same operations.
  pandas.DataFrame.merge → polars.DataFrame.join
    Notes: Merge DataFrames with a database-style join.
    Limitations: Map on/left_on/right_on directly; how maps to how in Polars; suffixes maps to suffix= (single tuple in Polars); validate and indicator are not supported.
    Discrepancies: pandas merge supports indicator column and validate mode; Polars join does not. Polars suffix is a single string, not a two-element tuple.
  pandas.DataFrame.pivot_table → polars.DataFrame.pivot
    Notes: Create a pivot table with aggregation over duplicate entries.
    Limitations: Use polars.DataFrame.pivot with aggregate_function; pandas aggfunc strings map to Polars aggregate_function strings.
    Discrepancies: pandas pivot_table supports multiple aggfuncs, margins, fill_value; Polars pivot supports one aggregate_function and simpler options.
  pandas.DataFrame.reset_index → No direct Polars equivalent; use with_row_index() only for row numbers  [no direct Polars equivalent — see guidance below]
  pandas.unique → polars.Series.unique
    Notes: Returns unique values from an array-like object.
    Limitations: Use Series/Expr unique depending on context; review order preservation if required.
    Discrepancies: pandas is top-level and array-like, while Polars applies unique through Series/Expr/DataFrame APIs.

used for data selection, renaming, and alignment in DataFrame operations.

Allowed inputs are:

  pandas.DataFrame.merge: Merge DataFrame or named Series objects with a database-style join.

A named Series object is treated as a DataFrame with a single named column.

The join is done on columns or indexes. If joining columns on
columns, the DataFrame indexes will be ignored.
  pandas.DataFrame.pivot_table: Create a spreadsheet-style pivot table as a DataFrame.

  pandas.unique: Return unique values based on a hash table.

Significantly faster than numpy.unique for long enough sequences.
