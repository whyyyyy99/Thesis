## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame.iloc → polars.DataFrame.slice
    Notes: Purely integer-location based indexing for selection by position.
    Limitations: Replace df.iloc[start:end] with df.slice(start, length); replace df.iloc[i] with df.row(i); replace df.iloc[:, j] with df.select(df.columns[j]).
    Discrepancies: pandas iloc supports full NumPy-style integer indexing; Polars uses separate slice/row/select methods.
  pandas.DataFrame.loc → polars.DataFrame.filter
    Notes: Access a group of rows and columns by label(s) or a boolean array.
    Limitations: Polars has no label-based index; replace df.loc[mask] with df.filter(mask) and df.loc[:, cols] with df.select(cols).
    Discrepancies: pandas loc relies on the Index; Polars is index-free and uses filter/select/slice for the same operations.
  pandas.DataFrame.set_index → No direct Polars equivalent; keep key columns as normal columns  [no direct Polars equivalent — see guidance below]
  pandas.DataFrame.to_csv → polars.DataFrame.write_csv
    Notes: Writes a DataFrame to a CSV file or returns CSV content as a string.
    Limitations: Basic CSV writing maps to df.write_csv; review pandas-specific options such as index, index_label, float_format, chunksize, and some compression/storage behavior.
    Discrepancies: pandas writes the index by default, while Polars has no pandas-style index and only writes columns.
  pandas.Series.any → polars.Series.any
    Notes: Checks whether any boolean value is true.
    Limitations: Review null handling; pandas skipna behavior may need manual handling.
    Discrepancies: pandas has skipna, while Polars boolean aggregation handles nulls differently.
  pandas.concat → polars.concat
    Notes: Concatenates multiple DataFrames or Series.
    Limitations: Map axis=0 to vertical concat; axis=1 to horizontal concat; review schema alignment.
    Discrepancies: pandas concat handles index alignment, while Polars concat uses explicit strategies such as vertical, horizontal, diagonal, or align.
