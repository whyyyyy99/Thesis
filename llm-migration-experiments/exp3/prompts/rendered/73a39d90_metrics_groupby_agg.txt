## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame.astype → polars.DataFrame.cast
    Notes: Cast one or more columns to a specified dtype.
    Limitations: Map simple dtype casts directly; pandas allows dict of {col: dtype} while Polars uses with_columns + cast per column.
    Discrepancies: pandas astype works on the whole DataFrame or per column via dict; Polars requires explicit per-column cast expressions.
  pandas.DataFrame.groupby → polars.DataFrame.group_by
    Notes: Groups rows by one or more columns for aggregation.
    Limitations: Use df.group_by(...).agg(...); as_index, level, and index grouping need manual review.
    Discrepancies: pandas can group by index/mapper and has as_index; Polars groups by columns/expressions and has no pandas-style index.
  pandas.DataFrame.loc → polars.DataFrame.filter
    Notes: Access a group of rows and columns by label(s) or a boolean array.
    Limitations: Polars has no label-based index; replace df.loc[mask] with df.filter(mask) and df.loc[:, cols] with df.select(cols).
    Discrepancies: pandas loc relies on the Index; Polars is index-free and uses filter/select/slice for the same operations.
  pandas.DataFrame.rename → polars.DataFrame.rename
    Notes: Renames columns or index labels.
    Limitations: Column rename maps to df.rename; index rename has no direct equivalent.
    Discrepancies: pandas can rename index and columns, while Polars only has column names.
