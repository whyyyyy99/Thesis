## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame.drop_duplicates → polars.DataFrame.unique
    Notes: Removes duplicate rows.
    Limitations: Use df.unique(subset=..., keep=...); review order preservation.
    Discrepancies: pandas uses drop_duplicates, while Polars uses unique.
  pandas.DataFrame.dropna → polars.DataFrame.drop_nulls
    Notes: Removes rows/columns with missing values.
    Limitations: Use drop_nulls(subset=...); for NaN, convert/drop separately.
    Discrepancies: pandas dropna handles NA/NaN broadly, while Polars separates null and NaN.
  pandas.DataFrame.join → polars.DataFrame.join
    Notes: Join columns of another DataFrame on index or on a key column.
    Limitations: Polars join requires explicit on= or left_on=/right_on= columns; index-based join (pandas default) has no equivalent since Polars has no index.
    Discrepancies: pandas join defaults to joining on index; Polars join always requires explicit key columns.
  pandas.DataFrame.set_index → No direct Polars equivalent; keep key columns as normal columns  [no direct Polars equivalent — see guidance below]
  pandas.concat → polars.concat
    Notes: Concatenates multiple DataFrames or Series.
    Limitations: Map axis=0 to vertical concat; axis=1 to horizontal concat; review schema alignment.
    Discrepancies: pandas concat handles index alignment, while Polars concat uses explicit strategies such as vertical, horizontal, diagonal, or align.

### Source pandas Behavior
Brief descriptions of the source pandas APIs to clarify their intended behavior.

  pandas.DataFrame.drop_duplicates: Return DataFrame with duplicate rows removed.

Considering certain columns is optional. Indexes, including time indexes
are ignored.

Only consider certain columns for identifying duplicates, by
default use all of the columns.
  pandas.DataFrame.dropna: Remove missing values.

See the User Guide for more on which values are
considered missing, and how to work with missing data.

Determine if rows or columns which contain missing values are
removed.

- 0, or ‘index’ : Drop rows which contain missing values.
  pandas.DataFrame.join: Compute join_index and indexers to conform data structures to the new index.

The other index on which join is performed.

It is either the integer position or the name of the level.

Whether to return the indexers or not for both the index objects.

Sort the join keys lexicographically in the result Index.
  pandas.DataFrame.set_index: Set the DataFrame index using existing columns.

Set the DataFrame index (row labels) using one or more existing
columns or arrays (of the correct length). The index can replace the
existing index or expand on it.
  pandas.Series.apply: Apply a function along an axis of the DataFrame.

Objects passed to the function are Series objects whose index is
either the DataFrame’s index (axis=0) or the DataFrame’s columns
(axis=1). By default (result_type=None), the final return type
is inferred from the return type of the applied function.
  pandas.concat: Concatenate pandas objects along a particular axis.

Allows optional set logic along the other axes.

Can also add a layer of hierarchical indexing on the concatenation axis,
which may be useful if the labels are the same (or overlapping) on
the passed axis number.
