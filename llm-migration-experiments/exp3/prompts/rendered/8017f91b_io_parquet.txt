  Limitations: Do not translate to df.to_pickle(...); use Python pickle.dump or a Polars columnar writer.
  Discrepancies: pandas provides a DataFrame method for pickle export, while Polars relies on Python pickle or dedicated tabular formats.

pandas.read_pickle:
  Suggested migration: No direct Polars equivalent; use pandas.read_pickle(...) + polars.from_pandas(...) if the object is a pandas DataFrame/Series.
  Notes: Loads a pickled pandas object or general Python object from a file-like source.
  Limitations: Do not translate to polars.read_pickle; load with pandas or Python pickle first.
  Discrepancies: pandas can return arbitrary Python objects, while Polars does not provide a generic pickle reader.
