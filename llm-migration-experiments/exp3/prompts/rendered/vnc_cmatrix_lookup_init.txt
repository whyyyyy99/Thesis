import pandas as pd

    def __init__(
        self,
        matrix: sc.sparse.csr_matrix,
        lookup: pd.DataFrame,
        CR: ConnectomeReader | None = None,
    ):
        if not sc.sparse.issparse(matrix):
            matrix = sc.sparse.csr_matrix(matrix)
        if not isinstance(matrix, sc.sparse.csr_matrix):
            matrix = matrix.tocsr()
        self.matrix = matrix

        if not isinstance(lookup, pd.DataFrame):
            raise ValueError("The lookup must be a pandas dataframe.")

        lookup = lookup.copy()
        lookup["row_index"] = lookup["index"].values
        lookup["column_index"] = lookup["index"].values
        self.lookup = lookup.drop(columns="index")

        if not all(self.lookup["row_index"].isin(range(self.matrix.shape[0]))):
            raise ValueError(
                "The lookup must include row indices up to the length of the matrix."
            )
        if not all(self.lookup["column_index"].isin(range(self.matrix.shape[1]))):
            raise ValueError(
                "The lookup must include column indices up to the length of the matrix."
            )

        self.CR = CR or default_connectome_reader()

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame → polars.DataFrame  [doc not in corpus — see guidance below]
  pandas.DataFrame.copy → polars.DataFrame.clone
    Notes: Make a copy of the DataFrame.
    Limitations: Use df.clone() in Polars; deep/shallow distinction does not apply since Polars DataFrames are immutable.
    Discrepancies: pandas copy(deep=True/False) controls deep vs shallow copy; Polars clone() always produces an independent copy because DataFrames are immutable.
  pandas.DataFrame.drop → polars.DataFrame.drop
    Notes: Drops specified row or column labels.
    Limitations: Column dropping maps to df.drop; row-label dropping needs explicit index column logic.
    Discrepancies: pandas can drop row/index labels, while Polars drops columns or filters rows explicitly.
  pandas.DataFrame.shape → polars.DataFrame.shape
    Notes: Returns DataFrame dimensions.
    Limitations: Use df.shape.
    Discrepancies: Mostly direct; no index metadata included.
  pandas.Series.isin → polars.Series.is_in
    Notes: Checks whether values are contained in a set/list.
    Limitations: Use is_in(values) in Series or expression context.
    Discrepancies: Mostly direct, but null/NaN behavior should be checked.
  pandas.Series.values → polars.Series.to_numpy
    Notes: Returns the Series values as an ndarray-like object.
    Limitations: Use s.to_numpy(); conversion may copy depending on dtype, nulls, and chunks.
    Discrepancies: pandas returns NumPy/extension ndarray-like values, while Polars conversion follows Arrow memory rules.
