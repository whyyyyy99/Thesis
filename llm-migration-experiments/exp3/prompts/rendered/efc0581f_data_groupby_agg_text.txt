## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame.groupby → polars.DataFrame.group_by
    Notes: Groups rows by one or more columns for aggregation.
    Limitations: Use df.group_by(...).agg(...); as_index, level, and index grouping need manual review.
    Discrepancies: pandas can group by index/mapper and has as_index; Polars groups by columns/expressions and has no pandas-style index.
  pandas.DataFrame.sort_values → polars.DataFrame.sort
    Notes: Sort the DataFrame by one or more column values.
    Limitations: Map by to the column name(s), ascending to descending=not ascending; na_position maps to nulls_last.
    Discrepancies: pandas sort_values uses by= and ascending=; Polars sort uses by= and descending=, with nulls_last controlling null position.
  pandas.Series.astype → polars.Series.cast
    Notes: Casts values to a specified dtype.
    Limitations: Use cast(dtype); use strict=False if failed casts should become nulls.
    Discrepancies: pandas supports errors, while Polars controls invalid casts mainly through strict.
