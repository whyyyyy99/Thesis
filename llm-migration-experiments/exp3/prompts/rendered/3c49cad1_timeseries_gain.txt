### Migration Guidance (for APIs without corpus docs)
For pandas APIs where the confirmed Polars target API was not found in the documentation corpus, the following textual migration notes from the knowledge base may still be helpful. Use them as guidance about the recommended migration approach, but verify correctness against your own knowledge of valid Polars APIs.


pandas.DataFrame:
  Suggested migration: polars.DataFrame
  Notes: Creates a two-dimensional tabular data object.
  Limitations: Use pl.DataFrame(data, schema=...); pandas index has no direct Polars equivalent.
  Discrepancies: pandas DataFrame has row index labels, while Polars DataFrame only has columns and row positions.

pandas.DataFrame.size:
  Suggested migration: df.height * df.width
  Notes: Returns number of elements.
  Limitations: Compute manually from height and width.
  Discrepancies: pandas exposes .size; Polars uses shape/height/width metadata.

pandas.DataFrame.sum:
  Suggested migration: df.select(pl.all().sum()) / pl.col(...).sum()
  Notes: Returns sum values.
  Limitations: Use expressions; review null/NaN and all-null behavior.
  Discrepancies: pandas has axis/skipna/min_count; Polars aggregates columns explicitly.

pandas.Series:
  Suggested migration: polars.Series
  Notes: Creates a one-dimensional labeled pandas array-like object.
  Limitations: Use pl.Series(name, values, dtype=...); pandas index has no direct Polars equivalent.
  Discrepancies: pandas Series has axis labels/index, while Polars Series has a name but no pandas-style index.

This operation copies data only when necessary.
     Example: Numeric data without nulls can be converted without copying data.

>>> arr = s.to_numpy()

Set writable=True to force data copy to make the array writable.

>>> s.to_numpy(writable=True).flags.writeable

Integer Series containing nulls will be cast to a float type with nan
representing a null value. This requires data to be copied.

>>> s = pl.Series([1, 2, None], dtype=pl.UInt16)

Set allow_copy=False to raise an error if data would be copied.
