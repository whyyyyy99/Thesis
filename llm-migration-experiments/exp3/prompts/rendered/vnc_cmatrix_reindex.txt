## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame.copy → polars.DataFrame.clone
    Notes: Make a copy of the DataFrame.
    Limitations: Use df.clone() in Polars; deep/shallow distinction does not apply since Polars DataFrames are immutable.
    Discrepancies: pandas copy(deep=True/False) controls deep vs shallow copy; Polars clone() always produces an independent copy because DataFrames are immutable.
  pandas.DataFrame.shape → polars.DataFrame.shape
    Notes: Returns DataFrame dimensions.
    Limitations: Use df.shape.
    Discrepancies: Mostly direct; no index metadata included.
  pandas.DataFrame.sort_values → polars.DataFrame.sort
    Notes: Sort the DataFrame by one or more column values.
    Limitations: Map by to the column name(s), ascending to descending=not ascending; na_position maps to nulls_last.
    Discrepancies: pandas sort_values uses by= and ascending=; Polars sort uses by= and descending=, with nulls_last controlling null position.
  pandas.Series.count → polars.Series.count
    Notes: Counts non-missing observations.
    Limitations: Use count for non-null values; add NaN handling if needed.
    Discrepancies: pandas counts non-NA values, while Polars count focuses on non-null values.
