## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame → polars.DataFrame  [doc not in corpus — see guidance below]
  pandas.DataFrame.columns → polars.DataFrame.columns
    Notes: Returns column labels.
    Limitations: Use df.columns.
    Discrepancies: Mostly direct; Polars columns are the main labels because there is no row index.
  pandas.DataFrame.iloc → polars.DataFrame.slice
    Notes: Purely integer-location based indexing for selection by position.
    Limitations: Replace df.iloc[start:end] with df.slice(start, length); replace df.iloc[i] with df.row(i); replace df.iloc[:, j] with df.select(df.columns[j]).
    Discrepancies: pandas iloc supports full NumPy-style integer indexing; Polars uses separate slice/row/select methods.
  pandas.read_csv → polars.read_csv
    Notes: Reads a comma-separated or delimited text file into a DataFrame.
    Limitations: Most basic CSV options map to pl.read_csv, but pandas-specific options such as index_col, converters, iterator, and some date parsing behavior need manual review.
    Discrepancies: pandas read_csv has broader legacy parsing options; Polars expects stricter CSV input and returns a Polars DataFrame without pandas-style index.
