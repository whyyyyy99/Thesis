### Source pandas Behavior
Brief descriptions of the source pandas APIs to clarify their intended behavior.

  pandas.DataFrame: Two-dimensional, size-mutable, potentially heterogeneous tabular data.

Data structure also contains labeled axes (rows and columns).
Arithmetic operations align on both row and column labels. Can be
thought of as a dict-like container for Series objects.
  pandas.Series: One-dimensional ndarray with axis labels (including time series).

Labels need not be unique but must be a hashable type. The object
supports both integer- and label-based indexing and provides a host of
methods for performing operations involving the index.
  pandas.to_datetime: Convert argument to datetime.

This function converts a scalar, array-like, Series or
DataFrame/dict-like to a pandas datetime object.

The object to convert to a datetime. If a DataFrame is provided, the
method expects minimally the following columns: "year",
"month", "day".

Convert this Series to a NumPy ndarray.

This operation copies data only when necessary.
     Example: Numeric data without nulls can be converted without copying data.
The resulting array will not be writable.

>>> arr = s.to_numpy()
>>> arr

>>> arr.flags.writeable

Set writable=True to force data copy to make the array writable.

>>> s.to_numpy(writable=True).flags.writeable
True

Integer Series containing nulls will be cast to a float type with nan
representing a null value. This requires data to be copied.

>>> s = pl.Series([1, 2, None], dtype=pl.UInt16)
>>> s.to_numpy()

Set allow_copy=False to raise an error if data would be copied.

>>> s.to_numpy(allow_copy=False)

Series of data type Array and Struct will result in an array with more than
