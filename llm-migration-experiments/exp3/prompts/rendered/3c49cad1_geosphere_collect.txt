### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame → polars.DataFrame  [doc not in corpus — see guidance below]

  pandas.DataFrame.values → polars.DataFrame.to_numpy
    Notes: Returns a NumPy representation of the DataFrame.
    Limitations: Use df.to_numpy(); conversion may copy depending on dtype/nulls/chunks.
    Discrepancies: pandas returns NumPy view/array-like, while Polars follows Arrow memory constraints.
  pandas.Series → polars.Series  [doc not in corpus — see guidance below]
  pandas.Series.astype → polars.Series.cast
    Notes: Casts values to a specified dtype.
    Limitations: Use cast(dtype); use strict=False if failed casts should become nulls.
    Discrepancies: pandas supports errors, while Polars controls invalid casts mainly through strict.
  pandas.Series.repeat → polars.Series.repeat_by
    Notes: Repeats elements of a Series.
    Limitations: For per-element repeat counts, use repeat_by(...).explode() in expression context.
    Discrepancies: pandas repeats Series values with index behavior; Polars has no index duplication semantics.
  pandas.to_datetime → polars.Expr.str.to_datetime
    Notes: Converts values to datetime.
    Limitations: Use string datetime parsing for string columns; numeric timestamp/date parsing needs separate handling.
    Discrepancies: pandas has one flexible top-level converter, while Polars uses expression/Series-based datetime conversion.

### Migration Guidance (for APIs without corpus docs)
For pandas APIs where the confirmed Polars target API was not found in the documentation corpus, the following textual migration notes from the knowledge base may still be helpful. Use them as guidance about the recommended migration approach, but verify correctness against your own knowledge of valid Polars APIs.


pandas.DataFrame:
  Suggested migration: polars.DataFrame
  Notes: Creates a two-dimensional tabular data object.
  Limitations: Use pl.DataFrame(data, schema=...); pandas index has no direct Polars equivalent.
  Discrepancies: pandas DataFrame has row index labels, while Polars DataFrame only has columns and row positions.

pandas.DataFrame.pop:
  Suggested migration: No direct equivalent; use col = df[name]; df = df.drop(name)
  Notes: Return and drop a column from the DataFrame in place.
  Limitations: Polars DataFrames are immutable; extract column with df[name] then reassign df = df.drop(name).
  Discrepancies: pandas pop modifies the DataFrame in place and returns the column; Polars requires a separate select and drop.

pandas.Series:
  Suggested migration: polars.Series
  Notes: Creates a one-dimensional labeled pandas array-like object.
  Limitations: Use pl.Series(name, values, dtype=...); pandas index has no direct Polars equivalent.
  Discrepancies: pandas Series has axis labels/index, while Polars Series has a name but no pandas-style index.
