## Knowledge

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame.apply → polars.DataFrame.map_rows
    Notes: Applies a function along DataFrame rows or columns.
    Limitations: Avoid direct UDF migration when possible; rewrite as native Polars expressions.
    Discrepancies: pandas apply(axis=...) is flexible, while Polars favors typed expressions and row UDFs are slower.
  pandas.DataFrame.drop → polars.DataFrame.drop
    Notes: Drops specified row or column labels.
    Limitations: Column dropping maps to df.drop; row-label dropping needs explicit index column logic.
    Discrepancies: pandas can drop row/index labels, while Polars drops columns or filters rows explicitly.
  pandas.DataFrame.insert → polars.DataFrame.insert_column
    Notes: Insert a column into the DataFrame at a specified location.
    Limitations: Use df.insert_column(index, series) in Polars; column must be a Polars Series.
    Discrepancies: pandas insert modifies in place; Polars insert_column returns a new DataFrame.
  pandas.DataFrame.rename → polars.DataFrame.rename
    Notes: Renames columns or index labels.
    Limitations: Column rename maps to df.rename; index rename has no direct equivalent.
    Discrepancies: pandas can rename index and columns, while Polars only has column names.
  pandas.DataFrame.replace → df.select(pl.all().replace(...)) / pl.col(...).replace(...)  [no direct Polars equivalent — see guidance below]
  pandas.DataFrame.reset_index → No direct Polars equivalent; use with_row_index() only for row numbers  [no direct Polars equivalent — see guidance below]
  pandas.Series.values → polars.Series.to_numpy
    Notes: Returns the Series values as an ndarray-like object.
    Limitations: Use s.to_numpy(); conversion may copy depending on dtype, nulls, and chunks.
    Discrepancies: pandas returns NumPy/extension ndarray-like values, while Polars conversion follows Arrow memory rules.

pandas.DataFrame.replace:
  Suggested migration: df.select(pl.all().replace(...)) / pl.col(...).replace(...)
  Notes: Replaces values according to scalar/list/dict mappings.
  Limitations: Use replace for direct value mapping; regex/nested pandas patterns need manual review.

  Suggested migration: No direct Polars equivalent; use with_row_index() only for row numbers

  Discrepancies: pandas has hidden index to reset; Polars has no hidden index.
