pandas.DataFrame:
  Suggested migration: polars.DataFrame
  Notes: Creates a two-dimensional tabular data object.
  Limitations: Use pl.DataFrame(data, schema=...); pandas index has no direct Polars equivalent.
  Discrepancies: pandas DataFrame has row index labels, while Polars DataFrame only has columns and row positions.

pandas.DataFrame.rename_axis:
  Suggested migration: No direct Polars equivalent
  Notes: Sets axis/index/column-axis name metadata.
  Limitations: Usually remove; use explicit column names if metadata matters.
  Discrepancies: pandas has axis-name metadata, while Polars does not use index-axis names.
