  pandas.DataFrame.iloc → polars.DataFrame.slice
    Notes: Purely integer-location based indexing for selection by position.
    Limitations: Replace df.iloc[start:end] with df.slice(start, length); replace df.iloc[i] with df.row(i); replace df.iloc[:, j] with df.select(df.columns[j]).

    Notes: Renames columns or index labels.
    Limitations: Column rename maps to df.rename; index rename has no direct equivalent.
    Discrepancies: pandas can rename index and columns, while Polars only has column names.
  pandas.DataFrame.set_index → No direct Polars equivalent; keep key columns as normal columns  [no direct Polars equivalent — see guidance below]
  pandas.concat → polars.concat
    Notes: Concatenates multiple DataFrames or Series.
    Limitations: Map axis=0 to vertical concat; axis=1 to horizontal concat; review schema alignment.
    Discrepancies: pandas concat handles index alignment, while Polars concat uses explicit strategies such as vertical, horizontal, diagonal, or align.
  pandas.merge → polars.DataFrame.join
    Notes: Joins two DataFrames using database-style join logic.
    Limitations: Map on, left_on, right_on, and how; review suffixes and null matching.
    Discrepancies: pandas merge has index-based joins, while Polars joins are column/expression-based and has no pandas-style index.

### Source pandas Behavior
Brief descriptions of the source pandas APIs to clarify their intended behavior.

  pandas.DataFrame: Two-dimensional, size-mutable, potentially heterogeneous tabular data.

Data structure also contains labeled axes (rows and columns).
Arithmetic operations align on both row and column labels. Can be
thought of as a dict-like container for Series objects.
  pandas.DataFrame.iloc: Purely integer-location based indexing for selection by position.

Changed in version 3.0: Callables which return a tuple are deprecated as input.

.iloc[] is primarily integer position based (from 0 to
length-1 of the axis), but may also be used with a boolean
array.

Allowed inputs are:

- An integer, e.g.
  pandas.DataFrame.index: The index (row labels) of the DataFrame.

The index of a DataFrame is a series of labels that identify each row.
The labels can be integers, strings, or any other hashable type. The index
is used for label-based access and alignment, and can be accessed or
modified using this attribute.
  pandas.DataFrame.rename: Rename columns or index labels.

Function / dict values must be unique (1-to-1). Labels not contained in
a dict / Series will be left as-is. Extra labels listed don’t throw an
error.

See the user guide for more.

Dict-like or function transformations to apply to
that axis’ values.
  pandas.DataFrame.set_index: Set the DataFrame index using existing columns.

Set the DataFrame index (row labels) using one or more existing
columns or arrays (of the correct length). The index can replace the
existing index or expand on it.
  pandas.concat: Concatenate pandas objects along a particular axis.

Allows optional set logic along the other axes.

Can also add a layer of hierarchical indexing on the concatenation axis,
which may be useful if the labels are the same (or overlapping) on
the passed axis number.
  pandas.merge: Merge DataFrame or named Series objects with a database-style join.

A named Series object is treated as a DataFrame with a single named column.

The join is done on columns or indexes. If joining columns on
columns, the DataFrame indexes will be ignored.

### Migration Guidance (for APIs without corpus docs)
For pandas APIs where the confirmed Polars target API was not found in the documentation corpus, the following textual migration notes from the knowledge base may still be helpful. Use them as guidance about the recommended migration approach, but verify correctness against your own knowledge of valid Polars APIs.


pandas.DataFrame:
  Suggested migration: polars.DataFrame
  Notes: Creates a two-dimensional tabular data object.
  Limitations: Use pl.DataFrame(data, schema=...); pandas index has no direct Polars equivalent.
  Discrepancies: pandas DataFrame has row index labels, while Polars DataFrame only has columns and row positions.

pandas.DataFrame.index:
  Suggested migration: No direct Polars equivalent; use explicit index column or with_row_index()
  Notes: Returns row labels of the DataFrame.
  Limitations: Do not translate to df.index; create an explicit column if row labels matter.
  Discrepancies: pandas has hidden row index, while Polars has no pandas-style index.

pandas.DataFrame.set_index:
  Suggested migration: No direct Polars equivalent; keep key columns as normal columns
  Notes: Sets DataFrame index using existing columns.
  Limitations: Do not translate to df.set_index; use key columns explicitly for joins, grouping, sorting, or filtering.
  Discrepancies: pandas hides key columns in an index, while Polars keeps keys as columns.
