import pandas as pd

def nearest_neighbor(
    treated_set: pd.DataFrame,
    control_set: pd.DataFrame,
    metric: str,
    covariates: Optional[Union[List[str], pd.Index[str]]] = None,
) -> pd.DataFrame:
    columns = treated_set.columns

    if not covariates:
        covariates = columns

    treated_array = treated_set[covariates].to_numpy().astype(float)
    control_array = control_set[covariates].to_numpy().astype(float)
    control_array_full = control_set.to_numpy()
    matched_group = pd.DataFrame(columns=columns)

    cov = np.array([])
    if metric == "mahalanobis":
        cov = np.cov(np.concatenate((treated_array, control_array)).T)

    for element_ss in treated_array:
        if metric == "mahalanobis":
            if cov.ndim == 0:
                inv_cov = 1 / cov
            else:
                try:
                    inv_cov = np.linalg.inv(cov)
                except np.linalg.LinAlgError:
                    raise ValueError(
                        "The covariance matrix is singular. Please, check the data."
                    )

            dist = [
                metrics.mahalanobis_metric(element_ss, element_bs, inv_cov=inv_cov)
                for element_bs in control_array
            ]

        else:
            metric_function = metrics.METRICS[metric]

            dist = [
                metric_function(element_ss, element_bs) for element_bs in control_array
            ]

        nn_index = np.argmin(dist)

        new_row = pd.DataFrame(control_array_full[nn_index], index=columns)
        matched_group = (
            new_row.transpose().astype(float).copy()
            if matched_group.empty
            else pd.concat([matched_group, new_row.transpose().astype(float)])
        )
        control_array_full = np.delete(control_array_full, nn_index, 0)
        control_array = np.delete(control_array, nn_index, 0)

    return matched_group.reset_index(drop=True)

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  pandas.DataFrame → polars.DataFrame  [doc not in corpus — see guidance below]
  pandas.DataFrame.astype → polars.DataFrame.cast
    Notes: Cast one or more columns to a specified dtype.
    Limitations: Map simple dtype casts directly; pandas allows dict of {col: dtype} while Polars uses with_columns + cast per column.
    Discrepancies: pandas astype works on the whole DataFrame or per column via dict; Polars requires explicit per-column cast expressions.
  pandas.DataFrame.columns → polars.DataFrame.columns
    Notes: Returns column labels.
    Limitations: Use df.columns.
    Discrepancies: Mostly direct; Polars columns are the main labels because there is no row index.
  pandas.DataFrame.copy → polars.DataFrame.clone
    Notes: Make a copy of the DataFrame.
    Limitations: Use df.clone() in Polars; deep/shallow distinction does not apply since Polars DataFrames are immutable.
    Discrepancies: pandas copy(deep=True/False) controls deep vs shallow copy; Polars clone() always produces an independent copy because DataFrames are immutable.
  pandas.DataFrame.empty → polars.DataFrame.is_empty
    Notes: Checks whether the DataFrame is empty.
    Limitations: Use df.is_empty().
    Discrepancies: Mostly direct, but pandas emptiness also relates to axes.
  pandas.DataFrame.reset_index → No direct Polars equivalent; use with_row_index() only for row numbers  [no direct Polars equivalent — see guidance below]
  pandas.DataFrame.to_numpy → polars.DataFrame.to_numpy
    Notes: Convert the DataFrame to a NumPy array.
    Limitations: Polars to_numpy() may require allow_copy=True for zero-copy conversion; null values must be handled before conversion.
    Discrepancies: pandas index is excluded automatically; Polars DataFrame has no index so all columns are exported directly.
  pandas.Index → polars.Series  [doc not in corpus — see guidance below]
  pandas.Series.T → No meaningful Polars equivalent; Series transpose is itself.  [no direct Polars equivalent — see guidance below]
  pandas.Series.to_numpy → polars.Series.to_numpy
    Notes: Converts the Series to a NumPy ndarray.
    Limitations: Use s.to_numpy(); conversion may copy if nulls, multiple chunks, or incompatible dtypes exist.
    Discrepancies: pandas and Polars both support NumPy conversion, but Polars follows Arrow zero-copy constraints.
  pandas.concat → polars.concat
    Notes: Concatenates multiple DataFrames or Series.
    Limitations: Map axis=0 to vertical concat; axis=1 to horizontal concat; review schema alignment.
    Discrepancies: pandas concat handles index alignment, while Polars concat uses explicit strategies such as vertical, horizontal, diagonal, or align.

### Migration Guidance (for APIs without corpus docs)
For pandas APIs where the confirmed Polars target API was not found in the documentation corpus, the following textual migration notes from the knowledge base may still be helpful. Use them as guidance about the recommended migration approach, but verify correctness against your own knowledge of valid Polars APIs.


pandas.DataFrame:
  Suggested migration: polars.DataFrame
  Notes: Creates a two-dimensional tabular data object.
  Limitations: Use pl.DataFrame(data, schema=...); pandas index has no direct Polars equivalent.
  Discrepancies: pandas DataFrame has row index labels, while Polars DataFrame only has columns and row positions.

pandas.DataFrame.reset_index:
  Suggested migration: No direct Polars equivalent; use with_row_index() only for row numbers
  Notes: Resets index into columns or drops it.
  Limitations: If pandas index contains meaningful values, preserve it as a real column before migration.
  Discrepancies: pandas has hidden index to reset; Polars has no hidden index.

pandas.Index:
  Suggested migration: No direct Polars equivalent; use a regular column or polars.Series instead.
  Notes: Immutable sequence used for indexing and alignment.
  Limitations: Do not translate to pl.Index; store index values as a normal column if needed.
  Discrepancies: pandas has Index objects for labels/alignment, while Polars has no pandas-style index.

pandas.Series.T:
  Suggested migration: No meaningful Polars equivalent; Series transpose is itself.
  Notes: Returns the transpose, which is self for Series.
  Limitations: Usually remove this call in migration.
  Discrepancies: pandas exposes .T, but one-dimensional Series transpose has no practical effect.
