## Rules
- Preserve the original logic and execution flow exactly; change only what is necessary for migration.
- Preserve the observable output contract, including required columns, column order when semantically meaningful, and compatible return type.
- Polars has no row index; handle index-dependent logic explicitly using column operations.
- Do not alter behavior on edge cases such as empty input, null values, duplicate keys, or single-column outputs.
- Prefer vectorised Polars expressions over element-wise operations wherever possible.
- Use valid Polars APIs only; do not copy pandas-only idioms into Polars.
- Include all necessary imports at the top.

### Confirmed Static API Mappings
These are predefined pandas-to-Polars mappings from a curated knowledge base. Use them as your primary migration reference.

  DataFrameGroupBy.ngroup → Use dense rank / group id mapping manually  [no direct Polars equivalent — see guidance below]
  pandas.DataFrame.drop → polars.DataFrame.drop
    Notes: Drops specified row or column labels.
    Limitations: Column dropping maps to df.drop; row-label dropping needs explicit index column logic.
    Discrepancies: pandas can drop row/index labels, while Polars drops columns or filters rows explicitly.
  pandas.DataFrame.groupby → polars.DataFrame.group_by
    Notes: Groups rows by one or more columns for aggregation.
    Limitations: Use df.group_by(...).agg(...); as_index, level, and index grouping need manual review.
    Discrepancies: pandas can group by index/mapper and has as_index; Polars groups by columns/expressions and has no pandas-style index.
  pandas.Series.astype → polars.Series.cast
    Notes: Casts values to a specified dtype.
    Limitations: Use cast(dtype); use strict=False if failed casts should become nulls.
    Discrepancies: pandas supports errors, while Polars controls invalid casts mainly through strict.
  pandas.SeriesGroupBy.first → df.group_by(group_cols).agg(pl.col("x").first().alias("x_first"))  [no direct Polars equivalent — see guidance below]

### Source pandas Behavior
Brief descriptions of the source pandas APIs to clarify their intended behavior.

  DataFrameGroupBy.ngroup: Number each group from 0 to the number of groups - 1.

This is the enumerative complement of cumcount.  Note that the
numbers given to the groups match the order in which the groups
would be seen when iterating over the groupby object, not the
order they are first observed.
  pandas.DataFrame.drop: Drop specified labels from rows or columns.

Remove rows or columns by specifying label names and corresponding
axis, or by directly specifying index or column names. When using a
multi-index, labels on different levels can be removed by specifying
the level.
  pandas.DataFrame.groupby: Group DataFrame using a mapper or by a Series of columns.

A groupby operation involves some combination of splitting the
object, applying a function, and combining the results. This can be
used to group large amounts of data and compute operations on these
groups.
  pandas.Series.astype: Cast a pandas object to a specified dtype dtype.

This method allows the conversion of the data types of pandas objects,
including DataFrames and Series, to the specified dtype. It supports casting
entire objects to a single data type or applying different data types to
individual columns using a mapping.
  pandas.SeriesGroupBy.first: Compute the first entry of each column within each group.

Defaults to skipping NA elements.

Include only float, int, boolean columns.

The required number of valid values to perform the operation. If fewer
than min_count valid values are present the result will be NA.

Exclude NA/null values.

DataFrameGroupBy.ngroup:
  Suggested migration: Use dense rank / group id mapping manually
  Notes: Numbers each group from 0 to n_groups-1.
  Limitations: Build unique group mapping and join back.
  Discrepancies: pandas has direct group id method; Polars needs explicit mapping.

pandas.SeriesGroupBy.first:
  Suggested migration: df.group_by(group_cols).agg(pl.col("x").first().alias("x_first"))
  Notes: Returns first value in each group.
  Limitations: Sort first if first value depends on order.
  Discrepancies: pandas has extra numeric_only/min_count; Polars uses expression aggregation.
