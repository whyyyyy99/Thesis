# Experiment 3: Hybrid Routing

Mapping-guided routing that combines static mappings, exact documentation
lookup, and embedding-based fallback retrieval.

- Routing and generation code: `code/`
- Static mapping: `knowledge/api_mapping.json`
- Shared documentation corpora: `../shared/knowledge/`
- Prompt template and rendered prompts: `prompts/`
- Retrieval records and generated Python: `results/`
- Canonical test results: `results/test_results_v3.csv`
- Final failure taxonomy: `results/taxonomy_classification_final.csv`
- Test notebooks and fixtures: `tests/`
