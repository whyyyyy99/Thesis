     Example: >>> df = pl.DataFrame({"foo": [1, 2, 3], "bar": [-1, 5, 8]})

>>> df.map_rows(lambda t: (t[0] * 2, t[1] * 3))
shape: (3, 2)

│ column_0 ┆ column_1 │
│ ---      ┆ ---      │

>>> df.select(
...     pl.col("foo") * 2,
