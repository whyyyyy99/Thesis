[3] Source API: pandas.DataFrame.loc
    Target API: polars.DataFrame.filter; polars.DataFrame.select; polars.DataFrame.row
    Description: Access a group of rows and columns by label(s) or a boolean array.
    Usage Limitations: Polars has no label-based index; replace df.loc[mask] with df.filter(mask) and df.loc[:, cols] with df.select(cols).
    Discrepancies: pandas loc relies on the Index; Polars is index-free and uses filter/select/slice for the same operations.

[4] Source API: pandas.DataFrame.merge
    Target API: polars.DataFrame.join
    Description: Merge DataFrames with a database-style join.
    Usage Limitations: Map on/left_on/right_on directly; how maps to how in Polars; suffixes maps to suffix= (single tuple in Polars); validate and indicator are not supported.
    Discrepancies: pandas merge supports indicator column and validate mode; Polars join does not. Polars suffix is a single string, not a two-element tuple.
