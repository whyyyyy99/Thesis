    Description: Applies a function group-wise.

[2] Source API: pandas.DataFrame.fillna
    Target API: df.fill_null(...) / pl.col(...).fill_null(...); use fill_nan for NaN
    Description: Fills missing values with a value or method.
    Usage Limitations: Use fill_null for nulls and fill_nan for floating NaN values.
    Discrepancies: pandas fillna covers several missing markers, while Polars distinguishes null from NaN.

[3] Source API: pandas.DataFrame.groupby
    Target API: polars.DataFrame.group_by
    Description: Groups rows by one or more columns for aggregation.
    Usage Limitations: Use df.group_by(...).agg(...); as_index, level, and index grouping need manual review.
    Discrepancies: pandas can group by index/mapper and has as_index; Polars groups by columns/expressions and has no pandas-style index.

[4] Source API: pandas.DataFrame.melt
    Target API: polars.DataFrame.unpivot
    Description: Unpivot a DataFrame from wide format to long format.
    Usage Limitations: Map id_vars to index=, value_vars to on=, var_name to variable_name=, value_name to value_name= in Polars unpivot.
    Discrepancies: pandas melt is aliased to DataFrame.melt; Polars renamed melt to unpivot in version 0.20. Both achieve the same wide-to-long reshape.

[5] Source API: pandas.DataFrame.pivot
    Target API: polars.DataFrame.pivot
    Description: Reshape DataFrame from long to wide format using column values as new column headers.
    Usage Limitations: Polars pivot syntax differs: use on= for column, index=, values=, aggregate_function=. No multi-value support like pandas.
    Discrepancies: pandas pivot uses index/columns/values kwargs; Polars uses on/index/values/aggregate_function and does not support multi-value pivoting in the same way.

[6] Source API: pandas.DataFrame.reset_index
    Target API: No direct Polars equivalent; use with_row_index() only for row numbers
    Description: Resets index into columns or drops it.
    Usage Limitations: If pandas index contains meaningful values, preserve it as a real column before migration.
    Discrepancies: pandas has hidden index to reset; Polars has no hidden index.

[7] Source API: pandas.Series.to_list
    Target API: polars.Series.to_list
    Description: Returns Series values as a Python list.
    Usage Limitations: Use s.to_list().
    Discrepancies: Both return Python lists, but pandas missing values and Polars null/NaN handling may differ.
